# Проверка волн в Chrome

Проверка идёт на **тестовой копии**, не на рабочем dashboard (8765): бинарник собран в scratchpad, запущен из
отдельной папки со своим `.env` (`PORT=8799`) и копией `data/reviews.sqlite`. В GitLab ничего не пишется: кнопки
«Отправить», reply, resolve, approve, retry, create MR на живых данных не нажимаются. Каждую страницу смотрим на
десктопе и на ширине 390px (iframe 390px).
